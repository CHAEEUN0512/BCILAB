# VOICE RUNNER 🎤

목소리 **높낮이**로 캐릭터의 높이를 실시간 조종하는 러너 게임.
방향키 대신 성대를 씁니다. 브라우저에서 `index.html` 을 열면 바로 실행됩니다.

```
목소리 높게  →  캐릭터 위로
목소리 낮게  →  캐릭터 아래로
소리 끊김    →  아래로 떨어짐  (이어지는 음 = 비행)
```

## 실행

마이크는 보안 컨텍스트에서만 열립니다. `file://` 로 열면 권한이 거부되니
로컬 서버로 띄우세요.

```bash
npx http-server . -p 8080
# → http://localhost:8080
```

마이크 없이 확인만 하려면 타이틀에서 **"키보드로 먼저 해보기"** (`↑` `↓`, `Shift` 실드).

## 처음 켜면 음역대를 잽니다

사람마다 목소리 음역이 다릅니다. 남성 저음과 여성 고음에 같은 매핑을 쓰면
누구는 화면 바닥에, 누구는 천장에 붙어버립니다. 그래서 시작할 때
**가장 낮은 음 / 가장 높은 음**을 1.6초씩 받아 개인 음역 `[fLow, fHigh]` 을
잡고, 그 구간을 로그 스케일로 0~1 에 매핑합니다. 음정은 지수적으로
올라가므로 로그를 취해야 "한 옥타브"가 화면에서 일정한 거리로 느껴집니다.

## 목소리를 어떻게 읽는가

`getUserMedia` → 밴드패스(65–1400Hz) → `AnalyserNode` → **정규화 자기상관**
으로 기본주파수 F0 를 추정합니다.

- 2배 다운샘플로 자기상관 연산량을 1/4 로 줄임 (프레임당 약 29만 곱셈, 60fps 여유)
- 구간 에너지는 제곱 누적합으로 O(1)
- 전역 최대의 90% 를 넘는 **첫** 봉우리를 선택 → 옥타브 아래로 잘못 잡히는 것 방지
- 포물선 보간으로 서브샘플 정밀도
- 5탭 중앙값 필터로 순간적인 튐 제거

합성 음성(배음 4개 + 노이즈) 기준 98Hz~698Hz 구간에서 오차 **0.2 cent 이내**,
잡음만 들어오면 clarity 0.13 으로 무성음 판정됩니다.

FFT 피크 대신 자기상관을 쓴 이유는, 사람 목소리는 배음이 기본음보다 강한 경우가
흔해서 스펙트럼 최대값이 F0 가 아닐 때가 많기 때문입니다.

## 방향키 대신 목소리라서 생기는 것들

단순히 입력 장치만 바꾼 게 아니라, **목소리에만 있는 성질**을 규칙으로 만들었습니다.

| 메커닉 | 조작 | 의도 |
|---|---|---|
| **높이 제어** | 음높이 | 기본. 아날로그 연속값이라 키보드보다 표현이 넓다 |
| **중력** | 침묵 | 숨을 쉬면 떨어진다. 어디서 끊을지가 곧 전략 |
| **실드** | 크게 소리치기 | 음량은 음높이와 독립된 축이라 동시 조작이 가능 |
| **그루브 배수** | 비브라토(목소리 떨기) | 최근 0.4초 음높이 표준편차로 감지. 잘 부를수록 점수가 는다 |
| **골든 라인** | 특정 음 정확히 유지 | 음정 안정성 자체를 보상. 유지할수록 배수 ×4 까지 |
| **사일런트 존** | 조용히 있기 | 규칙을 뒤집는 구간. 소리를 내면 다친다 |
| **멜로디 리플레이** | — | 플레이 중 부른 음을 기록해 게임오버 후 재생 |

화면 뒤에 남는 **네온 궤적**이 방금 낸 음의 궤적입니다 — 내 목소리가 그대로
그래프로 보이는 게 이 게임의 실시간 피드백입니다.

## 레벨

패턴 8종을 이어붙여 무한 생성합니다. 각각 요구하는 발성이 다릅니다.

- `stairs` 한 방향 음정 상승/하강
- `zigzag` 빠른 옥타브 도약
- `tunnel` 사인 곡선 통로 — 부드러운 글리산도
- `ceiling` / `floorUp` 낮은 음 / 높은 음 장시간 유지
- `golden` 정확한 음정 유지
- `silence` 발성 금지
- `arc` 장애물 없는 보너스 — 숨 돌리는 구간

특수 구간(`golden`, `silence`)은 최소 3200px 간격을 보장합니다.
속도와 통로 폭은 9000px 에 걸쳐 서서히 어려워집니다.

## 앞으로 넣어볼 것

- **듀엣 / 대전** — 두 사람이 각자 마이크로, 화음(3도·5도)을 맞추면 둘 다 부스트
- **장애물이 곧 악보** — 통로를 실제 음계 위에 배치해서, 클리어하면 아는 노래가 됨
- **모음 인식** — 포먼트로 "아/이/우"를 구분해 대시·점프·변신에 배정 (음높이와 독립된 세 번째 축)
- **박자 판정** — 리듬에 맞춰 끊어 부르면 콤보
- **노래 업로드** — 좋아하는 곡의 멜로디 라인을 그대로 레벨로 변환

## 파일

`index.html` 하나. 의존성·빌드 없음. Web Audio API + Canvas 2D.
