# 구면 뇌파 전파 시뮬레이터

머리를 반지름 9 cm 구로 단순화하고, 그 표면에서 뇌파(진행파)가 어떻게 퍼지는지 보여 주는 브라우저용 시뮬레이터입니다.
설치 없이 `index.html`을 브라우저로 열면 됩니다. three.js는 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 기능

| 모드 | 내용 |
|---|---|
| 점 소스 | 한 지점에서 동심원으로 퍼지는 파. `u = e^{-αd} cos(ωt − k·d)`, d는 구면 위 측지 거리 |
| 평면파 | 한 방향(뒤→앞, 앞→뒤, 좌↔우)으로 머리를 쓸고 지나가는 파 |
| 회전파 | 축(기본 Cz)을 중심으로 회전하는 파. 위상 특이점 2개 |
| 나선파 | 중심에서 감기며 퍼지는 파 |
| 파동방정식 | `u_tt = v²∇²u − 2γu_t + 소스`를 icosphere(40,962 정점) 메시의 그래프 라플라시안으로 직접 적분. 클릭으로 자극 |

- 주파수(δ–γ), 전파 속도(0.1–10 m/s), 감쇠, 시간 배율(슬로모션) 조절
- 진폭(전위) / 위상 색 표시
- 10-20 전극(Fpz, Fz, Cz, Pz, Oz, T7, T8)에서의 가상 EEG 파형과 Oz–Fpz 위상차 표시
- 예시 장면: 시각 α 전방 진행, 휴지기 α 후방 진행, 수면 방추파 회전, 자극 펄스

## 좌표계

- +y: 정수리(Cz), +z: 코(앞), +x: 피험자의 왼쪽
- 전극 위치는 10-20 체계를 구에 근사한 값입니다.

## 한계

실제 피질은 접혀 있고 두개골·두피의 볼륨 전도로 신호가 흐려집니다. 구의 아래 반쪽은 실제 머리에 없는 부분이며,
점 소스의 파가 반대편 극에 다시 모이는 현상은 구의 기하 때문에 생깁니다.
