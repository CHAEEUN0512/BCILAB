# 구면 뇌파 전파 시뮬레이터

머리를 반지름 9 cm 구로 단순화하고, 그 표면에서 뇌파(진행파)가 어떻게 퍼지는지 보여 주는 브라우저용 시뮬레이터입니다.
설치 없이 `index.html`을 브라우저로 열면 됩니다. three.js는 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 기능

| 모드 | 내용 |
|---|---|
| 점 소스 | 한 지점에서 동심원으로 퍼지는 파. `u = e^{-αd} cos(ωt − k·d)`, d는 구면 위 측지 거리 |
| 평면파 | 한 방향(뒤→앞, 앞→뒤, 좌↔우)으로 머리를 쓸고 지나가는 파 |
| 회전파 | 축(기본 Cz)을 중심으로 회전하는 파. 위상 특이점 2개 |
| 나선파 | 중심에서 감기며 퍼지는 파 |
| 파동방정식 | `u_tt = v²∇²u − 2γu_t + 소스`를 icosphere(40,962 정점) 메시의 그래프 라플라시안으로 직접 적분. 클릭으로 자극 |
| 국소 ↔ 전역 | 국소 패치(복소 Ginzburg–Landau 진동 매질)와 전역 진행파 모드 Γ가 양방향(K↓, K↑)으로 결합. 위상 특이점(소용돌이)을 찾아 표시. 클릭으로 패치 추가 |

- 주파수(δ–γ), 전파 속도(0.1–10 m/s), 감쇠, 시간 배율(슬로모션) 조절
- 진폭(전위) / 위상 색 표시
- 10-20 전극(Fpz, Fz, Cz, Pz, Oz, T7, T8)에서의 가상 EEG 파형과 Oz–Fpz 위상차 표시
- **채널 관찰**: 머리 위 전극(21개 10-20 채널)이나 파형 행, 채널 버튼을 누르면 그 채널에서 EEG 증폭기가 기록할 시계열을 표시
  - 샘플링 레이트(128/250/500/1000 Hz)로 샘플된 값 + 측정 잡음(백색 잡음 + 느린 배경 드리프트), µV 단위(파 최대 진폭 20 µV 가정)
  - 잡음 없는 원 신호, 비교 채널 원 신호를 함께 겹쳐 표시
  - 원 신호 진폭, 신호 대 잡음비, 주기당 샘플 수, 비교 채널 대비 위상차와 시간 지연
- 예시 장면: 시각 α 전방 진행, 휴지기 α 후방 진행, 수면 방추파 회전, 자극 펄스

## 국소 ↔ 전역 모드

```
dz/dt = (μ_i + iω_i) z − g(1 + iβ)|z|² z + D(1 + iα)∇²z + K↓·Γ·P_i + 잡음      (국소, 10,242 정점)
dΓ/dt = (μ_g + iΩ) Γ + c3|Γ|²Γ − c5|Γ|⁴Γ + K↑·⟨z·P̄⟩                            (전역 진행파 모드)
P_i = exp(−i k s_i)  : 전역 진행파의 공간 무늬
```

가설 버튼은 다음 세 가지를 비교합니다.

- **전역 먼저**: 전역 파가 스스로 켜지고(μ_g > 0, K↑ = 0), 1.2초 뒤 국소 패치가 켜짐 → 경계에서 소용돌이가 생기고 동기화 R이 떨어짐
- **국소 먼저**: 전역 모드는 쌍안정(μ_g < 0, c3 > 0)이라 혼자 켜지지 못하고, 패치가 차례로 켜지며 K↑로 문턱을 넘기면 갑자기 켜짐 → 소용돌이가 정리됨
- **동시 · 양방향**: 둘이 함께 시작해 서로 끌어당김

소용돌이는 level-4 icosphere 삼각형마다 위상의 감김 수를 계산해 찾습니다. 파라미터는 현상이 잘 보이도록 고른 값이며 실제 뇌의 측정값이 아닙니다.

## 전기 신호 모델 (관측 층: 두피 EEG)

피질 활동을 표면에 수직인 전류 쌍극자층(활동 1 = 0.05 nA·m/mm²)으로 보고, 4층 구 볼륨 도체에서 두피 전위를 계산합니다.

| 층 | 바깥 반지름 | 전도도 |
|---|---|---|
| 뇌 (쌍극자층 r = 7.85 cm) | 8.0 cm | 0.33 S/m |
| 뇌척수액 | 8.2 cm | 1.79 S/m |
| 두개골 | 8.7 cm | 0.0105 S/m |
| 두피 | 9.2 cm | 0.33 S/m |

- 구면조화 차수 l마다 라플라스 방정식을 해석적으로 풀어 전달 계수 H_l을 구하고(l ≤ 16), 두피 전위 = Σ H_l · (피질 무늬의 l 성분)으로 계산합니다.
- 두피 / 피질 표면 전위 비율: l=1 81 %, l=5 22 %, l=10 6 %, l=20 1 %. 파장이 몇 cm인 국소 진행파와 소용돌이는 두피에서 거의 사라집니다.
- 기준 전극: 연결 귓불(A1+A2)/2, 평균, Cz, 없음(무한원) 중 선택. 기준을 바꾸면 파형과 위상차가 달라집니다.
- 채널 관찰 패널에서 60 Hz 전원 잡음(3 µV)을 섞을 수 있습니다.
- 한계: 접힌 피질의 접선 방향 쌍극자, 개인별 두께·전도도 차이는 반영하지 않습니다. 파의 위치는 각도만 옮겨 전기 모델에 넣습니다.

## 좌표계

- +y: 정수리(Cz), +z: 코(앞), +x: 피험자의 왼쪽
- 전극 위치는 10-20 체계를 구에 근사한 값입니다.

## 한계

실제 피질은 접혀 있고 두개골·두피의 볼륨 전도로 신호가 흐려집니다. 구의 아래 반쪽은 실제 머리에 없는 부분이며,
점 소스의 파가 반대편 극에 다시 모이는 현상은 구의 기하 때문에 생깁니다.
