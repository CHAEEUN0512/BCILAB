# 청각 자극 재생기 (Auditory Stimulus Player)

EEG/BCI 실험용 **오디오 자극 재생 + 증폭기 트리거 전송** 프로그램의 프로토타입입니다.
의사 선생님들이 직접 쓰기 쉽도록 화면과 조작을 최대한 단순하게 만들었습니다.

## 무엇을 하나요?

1. **음악(오디오) 로드 → 목록에 담긴 순서대로 자동 재생**
2. **재생목록 자동 저장** — 한 번 추가한 음악은 프로그램을 껐다 켜도 그대로 남아 있습니다.
   원하면 개별 삭제 / 전체 삭제도 됩니다.
3. **재생 이벤트마다 증폭기(amplifier)로 트리거 코드 전송**
   - 재생 **시작**(각 트랙이 시작되는 순간) → 코드 `1`(기본값)
   - **정지**(사용자가 정지 버튼) → 코드 `2`
   - **종료**(목록 끝까지 재생 완료) → 코드 `3`
   - 코드 값은 설정에서 바꿀 수 있습니다.

## 화면 구성

```
┌─────────────────────────────────────────────┐
│ ● 증폭기 연결: …            [트리거 테스트][설정] │
│ 재생 목록 (위 → 아래 순서로 재생)                 │
│  1. 자극1.wav                                  │
│  2. 자극2.wav                                  │
│  [+ 음악 추가][선택 삭제][전체 삭제]     [▲][▼] │
│ 재생 중 ▶ 1. 자극1.wav                          │
│ [■■■■■■──────────]  (진행 막대)                 │
│  [   ▶  재생 시작   ] [  ■ 정지  ]              │
│ 트리거 로그                                      │
│  10:03:12 [트리거] start → 코드 1               │
└─────────────────────────────────────────────┘
```

## 설치 및 실행

```bash
pip install -r audio_stimulus_player/requirements.txt   # PySide6 설치
python -m audio_stimulus_player                          # 실행
```

> 실제 장비 없이도 바로 실행됩니다. 이때는 **테스트 모드**로 동작하며,
> 트리거가 화면 하단 로그에만 표시됩니다(증폭기로는 나가지 않음).

## 증폭기(트리거) 연결 방식

장비마다 트리거 수신 방식이 달라, 아래 4가지를 지원하도록 설계했습니다.
[설정] 버튼에서 방식과 코드를 고르면 됩니다.

| 방식 | 설명 | 추가 설치 |
|------|------|-----------|
| **패러렐 포트(LPT)** | 8bit TTL — **우리 앰프가 이 방식 (기본값)** | Windows: InpOut 드라이버 / Linux: `pip install pyparallel` |
| **테스트 모드** | 하드웨어 없이 로그로만 확인 | 없음 |
| **시리얼 / USB TTL** | USB 트리거 박스가 1바이트 코드를 받음 | `pip install pyserial` |
| **LSL 마커** | LabRecorder 등이 EEG와 같은 타임라인에 기록 | `pip install pylsl` (+ liblsl) |

- 장비 연결에 실패하면 **자동으로 테스트 모드로 전환**되어 실험이 중단되지 않습니다.
- [트리거 테스트] 버튼으로 실험 전에 증폭기가 신호를 받는지 미리 확인할 수 있습니다.

### 패러렐 포트(LPT) 설정 — Windows (실사용 환경)

우리 앰프는 패러렐 포트로 트리거를 받습니다. Windows 에서 패러렐 포트를 직접
제어하려면 **InpOut 드라이버**가 필요합니다(파이썬만으로는 불가).

1. **InpOut 드라이버 설치**
   - http://www.highrez.co.uk/downloads/inpout32/ 에서 내려받기
   - 압축 해제 후 `InstallDriver.exe` 를 **관리자 권한**으로 실행
   - 64bit Windows면 `inpoutx64.dll`, 32bit면 `inpout32.dll` 을
     이 프로그램 폴더(또는 `C:\Windows\System32`)에 복사
2. **포트 I/O 주소 확인**
   - 장치 관리자 → **포트(COM & LPT)** → 해당 LPT 포트 → 속성 →
     **리소스** 탭 → *I/O 범위*의 시작 주소 (예: `0378`, `DC00` 등)
   - 메인보드 내장 LPT면 보통 `0x378`, PCIe 패러렐 카드면 `0xDC00`,
     `0xE010` 같은 값일 수 있습니다.
3. **프로그램 [설정]** → 연결 방식 **"패러렐 포트(LPT)"** →
   *패러렐 주소*에 위 값 입력 (예: `0x378`) → 저장
4. **[트리거 테스트]** 로 앰프가 신호를 받는지 확인

> 참고: **USB→패러렐 어댑터(프린터용)** 는 TTL 트리거에 쓸 수 없습니다.
> 메인보드 내장 LPT, 또는 PCIe/ExpressCard 방식의 패러렐 카드를 써야 합니다.
> 노트북에 물리 패러렐 포트가 없으면 아래 "트리거 인터페이스 박스"를 참고하세요.

### 우리 장비: Compumedics Neuvo + CURRY

- Neuvo 증폭기는 **8bit TTL 트리거 입력(패러렐/LPT 방식)** 을 받으며,
  보낸 코드는 **CURRY** 소프트웨어에 이벤트 마커로 기록됩니다.
- 코드 범위는 **1~255** 를 쓰고, **0 은 "트리거 없음(리셋)"** 으로 취급합니다.
  (이 프로그램은 트리거 후 자동으로 0으로 리셋합니다.)
- CURRY 쪽에서 별도로 예약/금지된 코드가 있는지 실험 규약에 맞춰 코드 값을
  [설정]에서 정하면 됩니다.

**연결 방법 두 가지 — 노트북에 LPT 포트가 있는지로 갈립니다:**

| 상황 | 연결 방식 | 이 프로그램 설정 |
|------|-----------|------------------|
| 노트북/PC에 **물리 LPT 포트**(또는 PCIe 패러렐 카드)가 있음 | 그 포트 ↔ Neuvo 트리거 입력을 트리거 케이블로 연결 | 연결 방식 = **패러렐 포트**, 주소 입력 (위 안내) |
| 물리 LPT 포트가 **없음** (요즘 노트북) | **USB 트리거 인터페이스 박스**(예: NEUROSPEC MMBT-S) 를 노트북 USB ↔ Neuvo 트리거 입력에 연결 | 연결 방식 = **시리얼/USB TTL**, 박스가 잡힌 **COM 포트** 입력 |

> USB 트리거 박스(MMBT-S 등)는 PC에서 보통 가상 **COM 포트**로 잡히고,
> 바이트 하나를 보내면 그 값이 8bit TTL 로 Neuvo에 전달됩니다.
> 이 경우 InpOut 드라이버는 필요 없고, **시리얼 방식**을 고르면 됩니다.

## 실험을 위해 알려주셔야 할 정보 (하드웨어 확정 후)

정확히 붙이려면 아래 정보가 필요합니다:

1. **EEG 증폭기 제조사/모델** (예: BrainProducts, Neuroscan, Emotiv, g.tec 등)
2. **트리거 입력 방식** — 패러렐 포트 / 트리거 박스(USB·시리얼) / LSL / 기타
   - 시리얼이면 **포트 이름**(Windows `COM3` 등)과 **보드레이트**
   - 패러렐이면 **포트 주소**(보통 `0x378`)
3. **트리거 코드 규약** — 각 자극/이벤트에 어떤 숫자(0–255)를 쓸지
4. **사용할 노트북 OS** (Windows/Mac)와 오디오 출력 장치

## 저장 위치

설정과 재생목록은 사용자 홈 폴더의 `~/.audio_stimulus_player/` 에 저장됩니다.
- `config.json` — 트리거/증폭기 설정
- `playlist.json` — 재생목록

## 코드 구조

| 파일 | 역할 |
|------|------|
| `config.py` | 설정 로드/저장 (JSON) |
| `playlist.py` | 재생목록 모델 + 영구 저장/복원 |
| `triggers.py` | 증폭기 트리거 백엔드(mock/serial/lsl/parallel) — **교체 가능** |
| `player.py` | Qt 기반 오디오 재생 엔진 (순차 재생 + 이벤트 신호) |
| `ui.py` | 메인 화면 (단순 UI) |
| `__main__.py` | 실행 진입점 |
| `tests/test_core.py` | GUI 없이 돌리는 핵심 로직 테스트 |

## 알려진 프로토타입 한계 (다음 단계에서 개선)

- **트리거 타이밍**: 재생 시작 트리거는 `play()` 호출 직후 발사됩니다. 실제 소리가
  스피커로 나가는 순간과 수 ms~수십 ms 오차가 있을 수 있습니다. 밀리초 정밀도가
  필요하면 저수준 오디오 콜백 방식으로 교체 예정입니다.
- **곡별 트리거 코드**: 데이터 구조(`Track.code`)는 이미 지원하지만, 곡마다 다른
  코드를 부여하는 UI 는 아직 없습니다(자극 종류별 이벤트 구분이 필요하면 추가).
- 실제 증폭기 연동은 하드웨어 확정 후 검증이 필요합니다.
